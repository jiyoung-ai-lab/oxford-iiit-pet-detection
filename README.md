# Oxford-IIIT Pet Detection

An **object detection project** using the Oxford-IIIT Pet Dataset for **pet head / face detection**.

The project uses a **PyTorch-based SSD300 with a VGG16 backbone** to detect pet head regions.

> 🚧 **Status: In Progress**
>
> Currently working on data analysis and training the SSD300-VGG16 model.  
> Experimental results and analysis will be updated as the project progresses.
